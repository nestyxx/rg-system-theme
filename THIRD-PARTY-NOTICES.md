# Composants tiers

Le thème embarque les éléments suivants (aucun n'est téléchargé à l'exécution).

| Composant | Usage | Licence |
|---|---|---|
| [Inter](https://rsms.me/inter/) (via `@fontsource/inter`) | Police du texte (400 / 500 / 600, sous-ensemble latin, intégrée en data-URI) | SIL Open Font License 1.1 |
| [Space Grotesk](https://github.com/floriankarsten/space-grotesk) (via `@fontsource/space-grotesk`) | Police des titres et du logo (500 / 600) | SIL Open Font License 1.1 |
| [JetBrains Mono](https://www.jetbrains.com/lp/mono/) (via `@fontsource/jetbrains-mono`) | Police à chasse fixe (400) | SIL Open Font License 1.1 |
| [Lucide](https://lucide.dev/) | Tracés des icônes (`src/icons.mjs`), recopiés et adaptés | ISC |
| [Tailwind CSS](https://tailwindcss.com/) 4 | Compilation du CSS (outil de build uniquement, rien n'est livré hors du CSS généré) | MIT |
